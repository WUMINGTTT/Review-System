# 评价系统开发路线图

## 文档说明

本文档记录评价系统的完整开发规划，包含核心功能、扩展功能、各阶段任务划分及详细开发步骤。任务按执行顺序排列，不标注具体时间安排。

---

## 一、功能总览

### 1.1 核心功能（第一版必须完成）

| 模块 | 功能 | 说明 |
|------|------|------|
| 用户认证 | 注册、登录、JWT 鉴权 | 基础身份验证 |
| 角色权限 | 组织者、评审人、管理员 | RBAC 权限控制 |
| 评价管理 | 创建、编辑、删除评价活动 | 组织者核心操作 |
| 评分功能 | 逐人打分、自动保存 | 打分人核心操作 |
| 审核功能 | 通过、驳回评价 | 评审人核心操作 |
| 归档功能 | 查看已完成评价 | 历史记录查询 |
| 通知系统 | 任务提醒、状态变更通知 | 确保用户及时获知动态 |

### 1.2 扩展功能（后续版本逐步完成）

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P1 | 评价模板 | 预设维度和权重，快速创建评价 |
| P1 | 公开展示大厅 | 组织者可公开评价结果，所有用户可查看 |
| P2 | 数据分析 | 评价趋势、维度对比、排行榜 |
| P2 | 匿名评价 | 打分人身份保密 |
| P2 | 导出功能 | Excel/PDF/图片导出 |
| P3 | 高级权限 | 更细粒度的权限控制 |
| P3 | 批量操作 | 批量导入人员、批量打分 |

---

## 二、开发阶段规划（大纲）

### 阶段一：项目基础搭建

**目标**：完成项目骨架搭建，确保开发环境可运行

- 后端：Express + TypeScript + MySQL 连接
- 前端：Vue3 + Vite + Element Plus + 路由 + 状态管理
- 共享：类型定义基础结构

### 阶段二：后端核心功能开发

**目标**：完成所有 API 接口开发，可通过 Postman 测试

- 用户认证模块（注册、登录、JWT）
- 用户管理模块（CRUD）
- 评价活动模块（CRUD + 状态流转）
- 评分模块（保存、提交）
- 审核模块（通过、驳回）
- 通知模块（创建、查询、标记已读）

### 阶段三：前端核心功能开发

**目标**：完成所有页面开发，与后端对接

- 登录/注册页面
- 布局组件（PC 侧边栏 + 移动端 Tab 栏）
- 工作台页面
- 评价列表页面
- 创建/编辑评价页面
- 评分页面（PC 抽屉 + 移动端新页面）
- 审核页面
- 归档列表及详情页面
- 用户管理页面（管理员）
- 个人中心页面

### 阶段四：核心业务跑通

**目标**：完整业务流程可运行，移动端适配完成

- 前后端联调
- 移动端响应式适配
- 自动保存功能实现
- 通知系统对接
- 业务流程测试

### 阶段五：扩展功能开发

**目标**：按优先级逐步完成扩展功能

- P1：评价模板 + 公开展示大厅
- P2：数据分析 + 匿名评价 + 导出功能
- P3：高级权限 + 批量操作

## 四、技术要点备忘

### 4.1 后端关键技术

| 技术点 | 说明 |
|--------|------|
| JWT 鉴权 | 登录生成 Token，中间件验证 Token，Token 过期自动跳转登录 |
| 密码加密 | bcryptjs 加密存储，不可逆 |
| Prisma 中间件 | Prisma Client 扩展实现业务逻辑（如保存前加密密码） |
| 状态机 | 评价状态严格按流程流转，防止非法状态变更 |
| 分页查询 | Prisma 的 skip + take 实现分页，支持排序 |
| 统计查询 | Prisma 的 groupBy + 聚合函数实现统计分析 |

### 4.2 前端关键技术

| 技术点 | 说明 |
|--------|------|
| 响应式布局 | SCSS 媒体查询 + Element Plus 栅格系统 |
| 路由守卫 | beforeEach 钩子实现登录验证和权限控制 |
| 请求拦截 | Axios 拦截器自动添加 Token、处理 401 错误 |
| 状态管理 | Pinia 管理全局状态（用户信息、评价数据） |
| 自动保存 | 定时器 + 防抖 + localStorage 备份 |
| 组件懒加载 | 路由级懒加载，优化首屏加载速度 |

### 4.3 移动端适配要点

| 要点 | 说明 |
|------|------|
| 断点设置 | 768px 为分界点，≥768px 为 PC，<768px 为移动端 |
| 导航切换 | PC 侧边栏 + 移动端底部 Tab 栏 |
| 内容切换 | PC 表格 + 移动端卡片 |
| 触控优化 | 按钮最小 44px、输入框全宽、间距充足 |
| 弹窗适配 | PC 抽屉 + 移动端新页面 |
